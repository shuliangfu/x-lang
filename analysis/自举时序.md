## 1. 「自举完成」到底指什么（禁止混谈）

终局 **三义缺一不可**（`C迁移追踪.md` §0.1）+ 语义 + 产品：

| 层 | 代号 | 含义 | 今日 |
|----|------|------|------|
| 编排 | **MG** | 不依赖 `make` / `compiler/Makefile` 完成 bootstrap / L4 / 产品链 | ✅ wave941/942 物理删 + catalog 单权威 · 0 make bootstrap |
| 自举编译 | **BC** | 编译器自身 TU **不再**被 host `cc/gcc/clang` 编业务 C（含 glue/gen） | 🟡 开：glue/ast **壳 thin + 域 thin + 多叶 pure-owned leave**（bc residual present **~82**）；`pipeline_x` mega **仍 host-cc** |

| 语义 | v2==v3 | seed→v1→v2→v3 语义固定点（可选 D-03 bit-identical） | ⬜ 终局验收 |
| 产品 | L4+129 | 双端真冷 + `run-all-bstrict` **129** | ✅ **钉盘** `db809e00f`；tip 安全网 **`ffc0b646f`** |

> **产品 bstrict 全绿是必要非充分。** prove N / Stage2 / 工程轨绿 **单独不能** 说「可自举 / 自举完成」。

### 1.1 两条轨道（永远分清）

| 轨道 | 测什么 | 能否单独说「可自举」 |
|------|--------|----------------------|
| **工程轨** | prove IDENTICAL、R2、return-value 42、Stage2 子集 | **否** |
| **产品轨** | 本 SHA `xlang_asm` + option/hello/stdlib-import `-o` + 严格 129 | **必要** |

### 1.2 构建级别（谈完成必须 L4）

| 级 | 含义 | 放行？ |
|----|------|--------|
| L0–L1 | 旧二进制 / 热 relink 夹旧 `.o` | **禁止** |
| L2–L3 | 删相关 `.o` / bootstrap+g05 | 日常微步 **可** |
| **L4** | 全擦 `compiler|std|core` 全部 `.o` + 重链三二进制 + 矩阵 + 129 | **升钉 / 真删 / 谈完成** 默认 |
