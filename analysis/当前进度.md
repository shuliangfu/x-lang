### wave636 根因收口

| 债 | 产生点 | 状态 |
|----|--------|------|
| DEREF of `*[N]T` 加载首元 | `pipeline_asm_emit_deref_elf_c` 对 DEREF 结果 TYPE_ARRAY 仍按 esz 间接 load → INDEX 把标量当指针 | ✅ TYPE_ARRAY 结果 **leave-addr**（指针位即数组基址） |
| host-C `E * *` | `emit_type(PTR)` 对 TYPE_ARRAY 再 decay `E *` → 双星；`&a` 为 `E (*)[N]` | ✅ `emit_c_ptr_to_fixed_array_decl` → `E (*name)[N]` / 抽象 `E (*)[N]`；let/param 名嵌声明符 |

**语法契约（澄清 soft「解析序」）**：`*T[N]` = **array-of-pointers**（C 式，故意）；**pointer-to-array** 写 **`*[N]T`**。`let p: *i32[2] = &a` typeck 硬红 expected `[2]*i32` found `*[2]i32` 正确。

**impl method on INDEX**：typed `self: Pt` 下 `a[0].sum()` 本绿；untyped `self` 是更广 method 债，非本叶。

**数据流（五问）**：产生 = DEREF emit / host emit_type → 存储 = 指针值 / C 声明 → 消费 = INDEX / `(*p)[i]`。G.7：补全既有 deref + 既有 fixed-array peel/suffix，不新开第二套 INDEX。

**权威**：`pipeline_glue.c` · `pipeline_asm_emit_deref_elf_c`；`codegen.x` + `seeds/codegen_gen.linux.x86_64.c` · `emit_c_ptr_to_fixed_array_decl`。
