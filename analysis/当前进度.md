### wave591 根因收口

| 债 | 产生点 | 状态 |
|----|--------|------|
| arm64 `return t` / `let s=mk()` / `mk().f` >16B | freestanding sret 仅 ta==0 | ✅ AAPCS64 x8 sret |
| arm64 sret memcpy 参数序 | mov_arg0 为 no-op + pop 冲 dest | ✅ dest@x0 src@x1 n@x2 |
| x86 SysV sret 回归 | 同权威路径 | ✅ Ubuntu pure-asm 仍 42 |

**数据流（五问）**：产生 = freestanding 函数返回 >16B MEMORY；存储 = 帧 sret_home（hidden dest 指针）+ 调用方 home；消费 = STRUCT_LIT sret_direct / memcpy / FIELD load。wave590 仅 x86 SysV（rdi + GP shift）；arm64 无 x8 Indirect Result Location、无 sret 激活 → CG002；半开后 x86 式 push/pop memcpy 在 arm64 上 clobber dest → SIGSEGV。

**权威**：G.7 `pipeline_glue.c` — `func_sret_active`（ta==0\|\|1）· param_home 存 x8 · CALL/FIELD/let 装 x8（无 GP shift）· STRUCT_LIT sret_direct · `glue_emit_sret_memcpy_rbx_to_home` arm64 序。改 glue → `pipeline_x.o` + g05。
