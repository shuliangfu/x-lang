### 为何文档里有 `fn`/`Self`/`var`？

| 写法 | 说明 |
|------|------|
| **不是**产品矩阵债 | 标准面只认 `function` / `let` / `self: Type` |
| 来源 | wave445 探针曾用 Rust 风格 `fn`/`-> Self`/无类型 `self` 测 mono → 失败被记 soft |
| 正确探针 | `function` + 显式 `self: A` → 已绿；**勿**再用错误语法制造伪 gap |
| `var` | 非关键字；写 `var x` 整函数解析失败，用 `let` |
