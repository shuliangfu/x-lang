## 1. 新旧终局对照

### 1.1 方法文里的「旧终局」（仍正确的一半）

[`自举方法.md`](自举方法.md) 核心链：

```text
Cap → R 真迁 → M 去 pin → xlang_v2 == xlang_v3
```

| 仍正确 | 说明 |
|--------|------|
| 工程轨 ≠ 产品轨 | 14→15 号教训；bstrict + 矩阵 |
| L2 日常 / L4 整波 | skill §3.3 |
| Cap 解锁再批量 R | 比只刷 prove N 高效 |
| M 与 R 并行 | 不要等 H=0 再去 pin |
| seed 仅冷启动、退役后消双权威 | G.7 |

### 1.2 C迁移追踪的「新终局」（加长的终点）

| 层 | 含义 | 旧方法是否覆盖 |
|----|------|----------------|
| **语义 / pin** | v2==v3、M4、gen 退役 | ✅ Phase C/D 有 |
| **MG** | 物理删除 Makefile，xbuild 编排 | ❌ 几乎只当构建工具，终局未写「删 make」 |
| **BC** | 编译器自身不再 `$(CC) -c` 业务 C（含 **glue ~40k / ast_pool ~18k**） | 🟡 只写到 mega pin / rest；**未单列 glue 主债** |
| **PC** | 用户默认 asm，不默认 invoke_cc | 🟡 「尽量不调 cc」在 SELFHOST A；**未升为终局硬指标** |
| **阶段 9 residual** | 原 🔒 永久边界 → **必须消灭** | ❌ 方法仍写「syscall/crt 级除外」可长期留 |
| **阶段 10 L2 语言能力** | syscall/FFI/inline asm… 作消灭 residual 的前提 | ❌ 方法无 Track L2 |
| **阶段 11 xbuild** | 替代 make | ❌ 方法无 Track MG |

### 1.3 一句话关系

> **C迁移追踪 = 终局债地图 + 删 Makefile DAG**  
> **自举方法/步骤 = 怎么一波一波干活、怎么防假绿**  
> 两者应 **正交叠合**：步骤模板不变，**选题与终局勾选**改读 C迁移追踪。

## 3. 新方法观：五轨叠四轨（概念，不必改名四轨）

在不推翻 Cap/R/L/M 的前提下，脑中增加：

```text
        Cap / R / L / M     ← 正确性与产品 C-zero（方法原文）
                │
                ▼
        Track L2（语言 syscall/FFI…）  ← C迁移阶段 10
                │
                ▼
        Track G9（residual 消灭）      ← C迁移阶段 9（原 🔒）
                │
                ▼
        Track 8.3（glue/ast 池）       ← 删 make 前最大体积
                │
                ▼
        Track MG（xbuild / 删 Makefile）← 用户主闸门
                │
                ▼
        v2==v3 + 三义验收              ← 阶段 13
```

**选题规则（新）**：

1. 波次必须能回答：**推进了 C迁移哪一阶段？**（或产品 L4 红修）  
2. 若只闭 soft residual、不碰 pin/glue/MG → **工程进度**，进度文勿写成「逼近终局」。  
3. MG 可与 residual **并行**（11.0 瘦身），但 **11.3 物理删 make** 不得早于 BC 可承载。

## 4. 下一步自举怎么走？（核心）

### 4.1 不要做的两极

| 错误 | 表现 | 为何错 |
|------|------|--------|
| **A. 假装终局没变** | 继续只刷 untyped self / soft 叶，终局仍只报 v2==v3 | 永远删不掉 make；glue 40k 不动 |
| **B. 立刻全面换轨** | 停产品 Cap，全员写 xbuild / 语言 syscall | 产品红与 pin 债仍在；无测量大开 MG 会假绿 |
| **C. 跳去做 xlang test 全面实现 / string** | 自举未完成抢 P1/P2 | 路线图已禁；炸归因 |

### 4.2 推荐：继续「原来的干活方式」，换「地图与前排」

| 维度 | 接着原来 | 要改的 |
|------|----------|--------|
| **怎么干活** | 仍：一债一层、L2 探针、Ubuntu 金标、整波 L4、两进度文 | 选题从 C迁移 DAG 抽 |
| **报什么进度** | 仍：SHA、构建级别、矩阵 | 加：**C迁移阶段勾选** / glue 是否动 |
| **前排（≤3）** | 见下 §4.3 | 替换纯 soft 列表 |

### 4.3 建议前排（与钉盘 `53fd80927` 之后衔接）

在 **产品 tip L4 已绿** 的前提下，下一波**并行池**（按依赖选 1 条主 + 可选 1 条 MG）：

| 优先级 | 方向 | C迁移锚点 | 日常级别 | 说明 |
|--------|------|-----------|----------|------|
| **P0a** | **Makefile 规则迁移表 / 11.0.1–11.0.2** | 阶段 11.0 | 文档+闸门脚本 | **可立刻开**；不挡产品；为删 make 铺路 |
| **P0b** | **入口/产品硬叶**（若有红） | — | L2→整波 L4 | 当前钉盘绿则跳过 |
| **P1** | **8.3 地图：pipeline_glue / ast_pool 切片优先级** | 阶段 8.3 | 分析+探针 | 终局体积主债；先地图后动刀 |
| **P1′** | **Cap residual 硬叶**（untyped `self` 等） | 阶段 4.2 | L2 | **仅当**挡去 pin / 产品语义；勿无限 soft 扫 |
| **P2** | **7.4 typeck/codegen 去 pin 试烟** | 阶段 7.4 | L2/L3 | 与方法 Phase C 对齐 |
| **P3** | 阶段 10 能力（syscall 内建） | 阶段 10 | 大波 | **不要**在 8.3/7 未清时当唯一主线 |

**默认下一主波（综合 ROI）**：

```text
主：11.0.1 附录 E / Makefile 迁移表填实 + 产品路径「0-make」验收脚本（防回退）
辅（可选同波或紧随）：untyped self 若仍 skip 则 L2 硬叶；或 8.3 glue 爆炸半径图（只读/文档）
禁止：开 xlang test U1 实现、开 string、开 registry
```

> **「接着原来的写」** = 仍用 R2/Cap **操作模板**写代码与验证。  
> **「怎么样」** = **选题权威改成 C迁移追踪**；终局话术改成三义；进度前排加入 **MG + glue**。

### 4.4 决策树（下一波选题）

```text

  是 → 只修红（L2→L4），不谈 MG
  否 → 本波是否能推进「删 make 前置」？
```
