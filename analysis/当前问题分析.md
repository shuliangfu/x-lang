## 1. 本波已修根因（wave581）

### 1.1 OneFunc append 仍拒 name_len>64

- **现象**：默认 asm `let` 名 ≥75 → BLD001 `_main` UNDEF；host-C XP003 out_len=0  
- **产生点**：`pipeline_onefunc_append_let/const` 门控 `>64`；侧车 `grow_vec` 行宽 64；`copy64` memset/拷 64  
- **机制**：parser 已接受 ≤127；append 失败 → `parse_body_lets_into` return false → 整函数丢弃  
- **修法**：门控 127；行宽 128；ABI 名 *copy64 载荷 128  
- **PLATFORM: SHARED**

### 1.2 block / top-level 截断

- **产生点**：`pipeline_block_append_{let,const}` memcpy 64；`top_level_let_set` / hoist `>64`；top_level slice `>63`  
- **修法**：content cap 127；slice name_buf[128]；hoist 127  
- **PLATFORM: SHARED**

### 1.3 host-C emit_nm 拷贝 ci2<64

- **现象**：声明 64 个 `a` + NUL，return 完整 75 → 非法 C  
- **产生点**：codegen pin `while (ci2 < lname_len && ci2 < 64)` 但 `emit_nml = lname_len`  
- **修法**：拷贝环与 digit 后缀环 64→128；codegen.x + seed pin 同 commit  
- **PLATFORM: SHARED host-C**
