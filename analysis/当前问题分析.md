## 1. 本波已修根因（wave585）

### 1.1 形参名 content 仍卡 31（storage 与 Cap 主轨分叉）

- **现象**：`function f(pp…p: i32)` 参数名长度 ≥32 时 typeck `return expression type mismatch: expected i32, found ?`（调用 `f()` 无返回类型）；p31 绿  
- **产生点**：`FuncParamEntry.name[32]` + `pipeline_onefunc_append_param` `name_len>31`；parser `plen_param>31`；parser_asm `pname_buf[32]` / `param_name_len>31`  
- **机制**：wave577+ 已将多数 AST 名扩到 [128]，形参槽与 OneFunc 行仍 [32]；parser_asm 消费侧若在 *copy32 已写 128 后仍用 [32] 缓冲 → **std.* 大模块 import SIGABRT**  
- **修法**：content 127、缓冲/行 128；*copy32 ABI 名保留、payload 128；parser + seed + parser_asm 同向  
- **PLATFORM: SHARED**

### 1.2 权威路径

| 层 | 符号 |
