## 1. 本波已修根因（wave584）

### 1.1 Storage 已 128，library/import 侧门仍 63

- **现象**：`const <64+ident> = import(...)` 不登记 binding → 使用处解析失败；library 形 `return self.field == E.V` 扫描在长名上 fail-closed（回落 impl 路径通常仍可编，但权威门不一致）

- **机制**：wave577+ 已扩 AST/ImportEntry/LibraryParseResult 到 128，parse/setter/getter 分叉仍 63/64  
- **修法**：content 127、缓冲 128；select 行宽 128；dep path copy64 实际填 128；typeck.x + seed pin  
- **PLATFORM: SHARED**

### 1.2 Path 对齐 dep_ctx

- ImportEntry.path 可至 255，但 **dep_path_rows[128]** / typeck 权威 content 仍 **≤127**；本波 path 侧门与 copy 对齐 127/128，不另开 256 第二权威
