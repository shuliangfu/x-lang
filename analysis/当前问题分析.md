## 1. 本波已修根因（wave582）

### 1.1 Storage 已 128，parser/typeck 侧门仍 63

- **现象**：type alias 名 ≥64 → typeck `expected NAMED, found i32`；enum 类型名 ≥64 → check_block fail；变体长名/match 侧门  
- **产生点**：`parser_asm_type_alias_slice` / `type_ref` consume_qualified / enum register+variants / typeck `alias_name_len<=63` / Darwin **strict_minimal prebind_len<=63**  
- **机制**：wave577/581 已把 TypeAliasEntry/ModuleEnumEntry/AST 扩到 128，但 parser_asm 与 strict_minimal 仍按 63 拒收 → 别名未登记 / enum.Variant base 无 prebind  
- **修法**：全路径 content 127、缓冲 128；typeck.x + seed pin 同 commit；strict_minimal 与 heavy 同门控  
- **PLATFORM: SHARED**

### 1.2 Darwin 链路上权威易误判

- mac 链 **`bootstrap_seed_pipeline_filtered.o`（自 pipeline_x）+ `pipeline_glue_strict_minimal.o`**  
- **仅 rebuild `pipeline_glue_standalone.o` 不入 Darwin 产品链**
