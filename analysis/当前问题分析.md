## 2. wave446 已闭：lexer / 全库 `if condition must be bool` 真根因

### 2.1 症状（Trae 看到的）

- `xlang -c src/lexer/lexer.x` → `if condition must be bool` in `skip_whitespace_and_comments`
- 复杂条件形如 `l.pos + 1 < data.length && …` 与内层 `l.pos > (0 as usize)` 并存

### 2.2 最小复现（独立探针，不碰 lexer.x）

```x
export function main(): i32 {
  let pos: usize = 1;
  let n: usize = 3 as usize;
  if (pos < n) { return 1; }
  if (pos > (0 as usize)) { return 2; }  // 或 pos > (0)
  return 0;
}
```

- **仅** 同函数内先有 **`<` 比较**，再有 **`> (`** 时失败  
- `pos > 0` / `pos > z` / 先 `>` 后 `<` / 无 LT → **绿**  
- pipe_marker：失败 cond **kind=CALL(48) 或 ADD(4)**，type_ord=**-1**（根本不是 GT）

### 2.3 根因（parser · SHARED）

权威：`compiler/seeds/parser_asm/parser_asm_primary_slice.inc` 后缀环：见 `TOKEN_LT` 时用  
`parser_asm_skip_generic_angle_list_count_into_slice_c` 前瞻「`<…>` 后是否 `(`」以识别 `id<T>(…)`。

旧 skip **只计 `<>` 深度**，可跨 `{` `}` `return` `if` 一直扫到**后面另一条语句**的 `>`，再看到 `(` → 整段误收成 **generic CALL**。  
typeck 对 CALL 未解析出 TYPE_BOOL → 误报 *if condition must be bool*。

**不是** typeck 对 `&&` 链的类型推断 gap。

### 2.4 根修

- commit **`8a8aa1841`**：`parser_asm_lex_skip_slice.inc`  
  - 角列表遇语句边界（`{}` `;` `if/return/let/…`）或 depth==1 的裸 `)` → **中止并恢复 lex**  
  - primary 回落 relcompare，真比较 `<` / 后继 `> (` 语义正确  
- commit **`54293a3aa`**：`lexer.x` 结构体字面量尾 `;` + docblock 去掉字面 `/*` 序列（自举 `-c` 解析）

### 2.5 验证

- 探针 p2 / lt_gt / nest_open：编译 run OK  
- `./xlang -c src/lexer/lexer.x`：typeck 过（standalone `-o` 缺 runtime 符号属预期，非 typeck）

- 把 Darwin-only residual 写成金标阻塞  

### 3.4 为何会「碰到」`fn` / `Self` / `var`？

**正常用 X 语法做自举不会碰到。** 它们出现在 soft 清单里，是因为：

1. **wave445 探针历史**：有人用 Rust 风格 `fn clone(self) -> Self` 测 mono；产品权威路径是 `function clone(self: A): A`。错误语法失败 ≠ 语言缺口。  
2. **`var` 不是关键字**：变量只有 `let`/`const`；写 `var x` 解析失败（常表现成 P001/XP003），不是「var 推断未实现」。  
3. **R2 文档里的 `&var`**：指 seed 真迁时避开「取地址 / 函数指针」一类**未做的语法扩展**，不是「var 关键字」。  

**结论**：标准面 = `function` + `let` + 方法 `self: ExplicitType`。soft 表里写 `fn`/`Self` 是**防伪探针**，不是 wave447 工作项。 

### 3.3 Darwin residual（非阻塞）

- stage2 return-value parity gen2 exit=255  
- strict link 重复符号（Linux 允许多定义）
