- **修法**：一律 `codegen_out_buf_len()`；`ast_pool_bootstrap_glue` import path `out[128]`
- **commit**：`5bba2c7a4`

### 1.2 DepCtx sidecar module_at NULL（Ubuntu dep 不 co-emit）

- **产生点**：product `pipeline_run_x_pipeline_codegen_one_dep` → `emit(module_at)`；sidecar 空而 `driver_dep_module_buf` 已有 parse 结果
- **症状**：option/si BLD001 缺 `core_option_*`；生成 C 仅 entry
- **修法**：`run_x_pipeline_codegen_one_dep_emit` 入口 driver 槽回绑 + set_module（与 load_and_sync 闭包 rebind 同权威）
- **commit**：`265d37fd7` + `dc5cb9e64`（emit 入口）

### 1.3 操作纪律
