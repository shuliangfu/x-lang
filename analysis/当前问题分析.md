### 2.4 R2 候选详细评估：`runtime_time_os`

**文件**：[runtime_time_os.from_x.c](file:///home/xlang/x-lang/compiler/seeds/runtime_time_os.from_x.c)
**对应 .x**：[runtime_time_os.x](file:///home/xlang/x-lang/compiler/src/asm/runtime_time_os.x)（当前为 stub）

**函数清单**：
1. `time_now_monotonic_ns_c()` — 单调时钟纳秒（POSIX `clock_gettime` / Windows QPC）
2. `time_now_wall_ns_c()` — 墙钟纳秒（POSIX `clock_gettime` / Windows `GetSystemTimePreciseAsFileTime`）
3. `time_sleep_ns_c(int64_t ns)` — 睡眠纳秒（POSIX `nanosleep` / Windows `Sleep`）
4. `time_format_wall_rfc3339_c(uint8_t *buf, int32_t cap)` — UTC RFC3339 格式化
5. `time_wall_local_offset_min_c()` — 本地时区偏移（分钟）

**复杂度评估**：
- ✅ 无函数指针 / `&var`
- ✅ 无 `__thread` TLS 变量
- ✅ 平台分支清晰（`#ifdef _WIN32`）
- ⚠️ 需 OS API FFI（clock_gettime, nanosleep, gmtime_r, localtime_r）
- ⚠️ .x 需重写（当前 stub，无实质实现）

**风险**：
- OS API 需通过 C FFI（`extern function` 声明）调用
- Windows 分支需平台特定处理
- 时钟频率缓存（`static LARGE_INTEGER freq`）需在 .x 中处理

**建议**：wave501 可聚焦于 `runtime_time_os` 的 R2 迁移，作为验证 .x 对 OS 胶层表达能力的叶模块。
