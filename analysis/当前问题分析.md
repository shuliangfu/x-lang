   - 内存：nest20/25 平 ~408MB（原 22-40GB 指数级）

2. **codegen `emit_type_kind` 缺 TYPE_DYN 分支**（commit 2c2ec867e）
   - 根因：`emit_type_kind` / `type_kind_append_to_scratch` 有 TYPE_VOID(16) 等分支但**无 TYPE_DYN(17) 分支** → 落默认 `return -1` → "codegen failed at entry module emission" for any `dyn Trait` 参数
