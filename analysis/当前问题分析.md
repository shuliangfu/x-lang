## 1. 本波已修根因（wave580）

### 1.1 CALL / export 仍 63 门控 + out_cap=64

- **现象**：默认 asm `fn` 名 ≥64 → CG002 / BLD001；`-backend c` 绿  
- **产生点**：`glue_asm_build_call_export_sym_c_impl` `clen>63`；`out_cap=64` 且 `clen<out_cap`；mega_body `build_func_export_sym_c(..., 64)`；`build_dep_export` `pos < out_cap-1`  
- **修法**：门控 127；所有相关 out_cap **128**；dep export 满 cap 拷贝  
- **PLATFORM: SHARED**

### 1.2 ELF 表拷贝仍 64

- **产生点**：`pipeline_elf_ctx_add_label/add_sym/append_patch/append_reloc`  
- **修法**：行宽 128；link 名最长 128（Darwin `_`+127）  
- **纪律**：须重建 **pipeline_x.o**（Darwin first-def 胜出）

### 1.3 Darwin leading `_` 硬编码偏移 598052

- **产生点**：`seed_elf_ctx_set_macho_leading_underscore` / `backend_enc_arm64_call_c` 硬编码 pre-Cap offsetof  
- **机制**：Cap 后真字段 ~9e6；setter 写到幽灵槽，API 读真字段 → label/call 不一致  
- **修法**：G.7 唯一权威 `pipeline_elf_ctx_macho_leading_underscore` + 结构体字段写  
- **PLATFORM: MACOS|DARWIN**
