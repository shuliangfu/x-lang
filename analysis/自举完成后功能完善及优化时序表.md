禁止：toml 接 main、Io 注入、去染色、产品切 IR。

## P0 — 稳住基线（最先 · 强制）

- [ ] 钉盘「自举完成」SHA + tag（`自举进度.md` / G-07）
- [ ] mac + Ubuntu 各 ≥2 轮 L4 全擦 + 129，日志归档
- [ ] 发布门禁 / SELFHOST 清单开启
- [ ] **回退通道写清（Shell-Primary 时代）**：只保证 **删 Make 之后** 的钉盘/anchor 可回退；脚本入口统一 `./xbuild` / `bootstrap_driver_seed.sh`（勿假定仍有 Makefile 图）
- [ ] **bootstrap 产物 → 开发者 `xlang` 包装契约**：硬链接 / install 前缀 / `PATH` 约定写清（P0 可用包装，P1 再升格为正式 CLI 子命令体验）
- [ ] prove ≠ 产品绿 分轨声明
- [ ] 工作树卫生；CLI 冒烟快照（help / exit 契约）
- [ ] **性能回归基线落盘（双轨 + 最小测量脚本）**
  - 轨 A：**编译器吞吐**（自举/产品编译耗时 + 可选 Peak RSS；固定输入集）
  - 轨 B：**运行时关键路径**（1～2 条宏路径 + 少量微基准：调用/循环/分配；防「总吞吐绿、单路径滑坡」）
  - 数字 + 复现命令 + 测量脚本路径写入进度/CI 附件；后续 P2b 对照此基线

**不做**：新语法、大 std、产品切 IR、registry、统一 Reactor 大改；不维护「回退到删 Make 前 + 自动切回 Makefile」的双构建系统契约。

## P2 — 六轨 + 横切（P1 之后）

### P2a 语言

- [ ] string / str
- [ ] 泛型 / trait
- [ ] **诊断可读**（与 `explain` / CLI 错误格式持续对齐，非一次性）
- [ ] unsafe 边界
- [ ] async 语言面打磨（await/CPS 诚实；**非** T\* 主工程）

### P2b 编译优化（经典管线）

- [ ] 对照 **P0 双轨性能基线**（编译吞吐 + 运行时微/宏路径）再改
- [ ] 生成质量 / 体积（可扩微基准：热路径指令形态；细节见优化专文）
- [ ] mega pin 精简（O4 节奏）
- [ ] 先测再改；不与 residual / 去染色同 commit

### P2c std / 平台 / 安全

- [ ] 按 std 清单推进模块
- [ ] **平台边界双端持续验证**（至少 **mac + Linux**；SHARED 改动默认双端；勿等 Windows 才发现阻塞）
- [ ] **region 轻量关口**：经典管线 + 现有 async 路径上基础用例可跑（非 P4 融合叙事；见安全/region 专文）
- [ ] **region × async 不逃逸硬门禁**（P2c 起写清并进 gate，勿等到 P4）：禁止将带 region 借用生命周期的值传入 `spawn` / JoinSet / 跨任务调度边界（细则专文；时序只钉闸门）
- [ ] 安全边界跟进（unsafe / cancel / 超时与 region 同 PR 意识）

### P2d IR（旁路 · 不挡产品）

- [ ] IR-Phase 0–3 旁路可跑
- [ ] **禁止**默认产品路径切换（须 ≥Phase 5 + oracle，见 P3/P4）

### P2e `xlang.toml` Core

**TOML-1**

- [ ] `project_config`：load / defaults / 校验
- [ ] find-up `xlang.toml`；`build` / `run` merge CLI
- [ ] `--print-config`
- [ ] 默认引擎 M0（无 build.x 也能 build）
- [ ] `[features].*` bool → cfg

**TOML-2**

- [ ] `profile.dev` / `profile.release` + `--release`
- [ ] `default-target` 与 `-target` 一致
- [ ] （可选）交叉编译 / 目标三元组 **最早可用点**文档化（能编什么、不能编什么）

### P2f 全面异步（主轨启动）

**开闸**：P0 成立 + async gate 绿 + 无双栈 + 符号表/依赖清单有维护。

**ASYNC-1（先做 · Linux 金标）**

- [ ] 调用图审计 + 对外 API 白名单
- [ ] 统一 Reactor / EventLoop（单入口）
- [ ] **Evented 接口按完成语义设计 Buffer 所有权转移**（completion-based；为 ASYNC-3 Windows IOCP/Proactor 预留，禁止只按 epoll 就绪通知锁死抽象）
- [ ] Linux io_uring 主路径打穿
- [ ] net 全异步：accept / read / write / connect + 取消/超时
- [ ] spawn / JoinSet / Context 产品化（遵守 P2c **region 不逃逸**）
- [ ] 单线程高并发 echo（或有限 HTTP）基准可复现
- [ ] **mac + Linux 行为对照**（mac 可 sync 回退，但 SHARED 面不得只绿一端）

**ASYNC-2（接上）**

- [ ] Io / Executor 接口定稿
- [ ] ThreadedIo → EventedIo → TestIo
- [ ] std.io + std.net 一点双路径迁移
- [ ] **双路径期着色策略**（写进 PR/专文一页即可）：编译器/工具链默认 Threaded/sync；产品库允许双路径但须标权威与迁移方向；禁止工具链半同步半 Evented 无纪律蔓延（T\* 再收口）
- [ ] 双后端对照测试

**P2f 不做**：一次性去染色全语言；要求 mac/Windows Evented 齐才收 ASYNC-1；第二套 scheduler；在 region 不逃逸门禁未进 gate 前放开 spawn 产品化。

### P2g 测试中间层 · 文档骨架 · 交叉编译（轻）

- [ ] **集成 / 端到端冒烟矩阵**：`build` + `run` + `test` 组合稳定进主套件（T1 与 T2 之间的中间层）
- [ ] **语言参考 + std 文档骨架**可生成，并挂 CI（不必全文写完；防 P1 教程与 P3 `doc` 之间断层）
- [ ] （可选）交叉编译 / 三元组最小探针（能失败但要有明确错误）
