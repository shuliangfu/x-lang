# 变量与常量

## let（变量）

- 语法：`let name: Type = init_expr;` 或 **`let name: Type;`**（省略 `=`，零初始化）  
  - 可选 **`mut`**：`let mut name: Type = …` / `let mut name: Type;`（wave385）— 与不写 `mut` 语义相同。
- **类型注解**：必须写，无类型推断省略形式。  
  - 省略时产品路径硬失败 **`parse error[P010]`**（wave422）：`let requires type annotation (no type inference; …)`，不再只表现为软 **P001**「no functions」/ 链接缺 `_main`。
- **初始值**：
  - 带 `=`：按右侧表达式初始化（与上下文类型 coerce 规则一致）。
  - **省略 `=`**：按声明类型**零初始化**（栈槽清零），语义等价于 `let buf: u8[N] = []`、`let n: i32 = 0` 等；适用于标量、指针、定长数组、结构体、SIMD 向量等所有 `let` 可声明类型。
  - **`const` 仍须** `= init_expr`（编译期常量表达式）。
- **作用域**：块内；从声明处到块结束。
- **可变性**：当前语义下 **let 绑定默认可重新赋值**（如 for step 中 `i = i + 1`）。  
  - 可选关键字 **`mut`** 仅作拼写标记（Rust 习惯），**不改变**可变性；将来若引入默认不可变绑定，再区分语义。  
  - **`const` 后不可写 `mut`**。

示例：

```su
let x: i32 = 1;
let mut y: i32 = x + 2;   // 与 let y 同语义（可再赋值）
y = y + 1;
let buf: u8[64];          // 等价 let buf: u8[64] = []（全零）
let z: i32x4;             // 向量零初始化
let p: Point;             // 结构体零初始化
let total: isize = 0;   // 字面量 0 按 isize 收窄
let p: *u8 = 0;         // 指针语境下的 null（字面量 0）
let q: *u8 = null;      // wave668：关键字 null ≡ 指针语境 0（比较/return/实参同）
```

## 上下文类型

`let` / `const` 声明右侧的整型字面量、`0` / **`null`** 空指针等，按左侧**类型注解**做编译期 coerce（与赋值、`return`、实参、struct 字段规则一致）。须写类型注解；无「省略类型的 let 推断」。关键字 `null` 降为 EXPR_LIT 0 并打 var_name 标签（wave670）；typeck **仅**允许指针语境（let/assign/return/call/cmp）；裸 `0` 仍可整数/指针 coerce。

`const` 与 `let` 在字面量 coerce 上行为一致，例如 `const MAX: u32 = 8` 无需 `8 as u32`。

## const（常量）

- 语法：`const name: Type = init_expr;` 或 `const name = init_expr;`（类型可选，由初始化表达式推断 — **wave423** 已上：解析允许省略 `: Type`，typeck 从 init 戳记类型；非法形式仍 **P010**）。
- **初始值**：必须为**常量表达式**（编译期可求值，如字面量、其它 const、简单运算）。
- **作用域**：块内或顶层；从声明处到块/模块结束。
- **不可变**：const 绑定不可重新赋值，生成 C 时对应 `const`。

示例：

```su
const N: i32 = 10;
let x: i32 = 1 + 2;
let y: i32 = x + N;
```

## 块与顺序

- 块内可有多条 `const` 与 `let`，按书写顺序出现；使用前须已声明。
- const 与 let 后可跟循环、defer、标签/goto/return，最后可为**最终表达式**（块的值）；若函数需要返回值，通常用 `return expr;` 显式返回。
